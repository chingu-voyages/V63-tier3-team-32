How web, edge and server fit together

Event Planner is three packages in one pnpm workspace. In production, the edge is the only door in. Locally, Vite stands in for it.

Production: two Workers behind one URL

Local with pnpm dev: Vite replaces the edge

What each package is for

PackagePurposeLocal developmentProduction
web React 19 and Vite front end. Calls the API through Hono's typed client and imports only the route type from server. Vite on :5173 with hot reload. Proxies /api to the server. Built to web/dist and served as static assets by the edge. Same origin as the API, so no CORS.
edge Public entry point. Gates /api/* with the shared access key and signs the service token. Not used by pnpm dev. Run it only with pnpm dev:edge to check the real gate, binding and assets. Cloudflare Worker event-planner. Only /api/* runs Worker code. The server is reached over a service binding.
server Hono API. Owns all data access and the Supabase secret key. Rejects any request without a valid service token. Plain Node process on :3000, started with tsx watch --env-file=.env. Cloudflare Worker event-planner-server. Its public URL stays closed because every /api/* route needs a token.

Environment variables and why each exists

VariableNeeded byWhyWhere it lives
SERVICE_JWT_SECRET Edge and server. Also Vite in pnpm dev. Shared HS256 key. The signer makes the 60 second token and the server verifies it. If the two values differ, the server rejects every request. Local: server/.env for pnpm dev; edge/.dev.vars and server/.dev.vars for dev:edge. Deployed: wrangler secret put in both edge/ and server/.
ACCESS_KEY Edge only The shared passphrase users type in. It proves a person is allowed in. The edge strips it before the request goes on. Local: edge/.dev.vars, only for dev:edge. Deployed: wrangler secret put in edge/.
SUPABASE_URL Server only Tells the server which Supabase project to talk to. Local: server/.env. From Project Settings, Data API.
SUPABASE_SECRET_KEY Server only Lets the server read and write all tables. It bypasses RLS, which is why only the server may hold it and the web bundle must never see it. Local: server/.env. From Project Settings, API Keys. Share it through a password manager.

Both checks fail closed. A Worker missing its secret answers 500, never "allow". Which of these files you need depends on what you run: server only or web with server needs just server/.env; edge only needs just edge/.dev.vars.
